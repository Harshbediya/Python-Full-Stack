📌 Section 1: Background Colors & Images

1.1 Background Color

background-color: #FF6B6B;

Sets a solid color background using hex codes (#RRGGBB) or color names

1.2 Background Gradient

linear-gradient(45deg, #FF6B6B, #4ECDC4)

Gradient creates smooth color transition. 45deg = angle, then list colors

1.3 Background with Opacity

rgba(255, 107, 107, 0.7) - Semi-transparent

rgba = Red, Green, Blue, Alpha(transparency). Alpha 0=transparent, 1=solid

✨ Section 5: Hover Effects

5.1 Basic Hover - Change Color

On hover, the background color changes instantly
CSS: .button:hover { background-color: newcolor; }

5.2 Hover with Scale

On hover, button grows using transform: scale(1.1)
scale(1.0) = normal, scale(1.2) = 120% size

5.3 Hover with Shadow

On hover, box-shadow creates depth effect
Shadow moves down: 0px 8px 15px rgba(0,0,0,0.3)

5.4 Hover with Rotate

On hover, element rotates using transform: rotate(5deg)
Positive degrees = clockwise, negative = counter-clockwise

5.5 Multiple Hover Effects

Multiple transforms together create complex animations
Combine: scale + rotate + translate + color changes

🔄 Section 6: Transform Properties

6.1 Rotate Transform

rotate(5deg)
rotate(45deg)
rotate(90deg)

rotate(5deg) = rotate 5 degrees clockwise
rotate(-45deg) = rotate 45 degrees counter-clockwise

6.2 Scale Transform

scale(1.0) - Normal
scale(1.5) - 150%
scale(2) - 200%

scale(1) = 100% (original)
scale(1.5) = 150% (larger)
scale(0.5) = 50% (smaller)

6.3 Translate Transform

translate(20px, 10px)
translateX(50px)
translateY(30px)

translate(x, y) = move x pixels right, y pixels down
translateX = move only horizontally
translateY = move only vertically

6.4 Skew Transform

skew(10deg)
skew(20deg, 10deg)

skew(10deg) = slant 10 degrees on X axis
skew(x, y) = slant both x and y axes

⏱️ Section 7: Transitions (Animations)

7.1 Transition Duration

transition-duration: 0.3s; = animate over 0.3 seconds
Smaller time = faster animation

7.2 Transition Timing Function

ease = default (slower at start/end)
linear = same speed throughout
ease-in = starts slow
ease-out = ends slow

7.3 Shorthand Transition

Shorthand: transition: all 0.3s ease 0s;
All = animate ALL properties
Or specify: property duration timing delay

7.4 Transition Delay

transition-delay: 0.5s; = wait 0.5 seconds before animating
Great for staggered animations!
