Important CSS Background Properties

background-color: Sets the background color of an element.
background-image, background-repeat, background-position, background-size: Adds, places, and scales a background image.
background-repeat: Controls whether a background image repeats. Common values are repeat, no-repeat, repeat-x, and repeat-y.
background-attachment: Controls whether the background scrolls with the page. Common values are scroll, fixed, and local.
background-origin and background-clip: Control where the background starts and how far it is painted: border-box, padding-box, or content-box.
background-blend-mode: Defines how background layers blend together.
background: Shorthand for setting several background properties in one declaration.
