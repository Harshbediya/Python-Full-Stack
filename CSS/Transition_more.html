Important Transition Properties

transition-property: tells which CSS property will animate.
transition-duration: sets how long the animation lasts.
transition-timing-function: controls the speed pattern like ease, linear, ease-in, ease-out, ease-in-out.
transition-delay: adds a waiting time before the transition starts.
transition: shorthand for all transition properties in one line. 

.element {
    transition-property: width, height, background-color;
    transition-duration: 1s, 0.8s, 1.2s;
    transition-timing-function: ease-in-out, linear, ease;
    transition-delay: 0.2s, 0s, 0.5s;
    transition: all 1s ease-in-out 0.2s;
}
