Important CSS Properties

CSS properties control how HTML elements look, where they appear, and how they behave.

1. Color and Background

color changes text color. background-color changes the background.

Colored text and background

2. Text Properties

font-size, font-weight, text-align, text-transform, and text-decoration style text.

Styled text

3. Width and Height

width controls an element's horizontal size. height controls its vertical size.

150 x 80 px

4. Box Model

padding adds space inside the border. margin adds space outside it. border draws an edge.

Content inside the box

5. Border and Radius

border-radius rounds corners. Use border to set width, style, and color together.

Rounded box

6. Flexbox

display: flex creates a flexible row or column. justify-content and align-items align its children.

OneTwoThree

7. Grid

display: grid creates rows and columns. grid-template-columns defines the column sizes.

Column 1Column 2

8. Display

display decides how an element participates in layout. Common values are block, inline, inline-block, and none.

Inline blockInline block

9. Position

position: relative creates a reference box. position: absolute places an element relative to that box.

Bottom right

10. Hover and Transition

:hover applies styles when the pointer is over an element. transition makes changes smooth.

Hover me

11. Opacity and Shadow

opacity controls transparency. box-shadow adds a shadow around a box.

Transparent shadow

12. Responsive Design

@media changes styles for different screen sizes, so the page works on phones and computers.
