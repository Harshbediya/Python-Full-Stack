Web Concepts I've Learned

Display Property

Controls how elements are rendered on the page

  • block - Takes full width, starts new line
  • inline - Flows with text, no width/height
  • flex - Flexible box layout
  • grid - 2D grid layout

Flexbox Layout

One-dimensional layout method for arranging items

  • justify-content - Horizontal alignment
  • align-items - Vertical alignment
  • flex-direction - Row or column
  • flex-wrap - Wrap items or not

Hover & Transitions

Interactive effects when users interact with elements

  • Hover - Changes when mouse is over element
  • Transition - Smoothly animates changes
  • Transform - Rotate, scale, skew elements

Forms & Validation

Collecting user input with proper structure

  • Input types - text, email, password
  • Labels - Associated with inputs
  • Validation - Check data format
  • Feedback - User knows if correct
